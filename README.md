# Олимпияfood — Android-приложение

Обёртка (WebView) над сайтом https://falling-dust-d961.olimpiafood.workers.dev/
с офлайн-кешем. Адрес сайта задаётся в `MainActivity.START_URL`.

## Как работает кеш
- Каждый запуск приложения сначала запрашивает свежие данные с сайта и обновляет локальную копию.
- Нет интернета (или сервер недоступен) — показывается последняя сохранённая версия.
- Кешируются страница, скрипты, стили, картинки, шрифты и запросы за данными (GET).
- Файл, удалённый на сайте (404/410), удаляется и из кеша.

## Как получить APK
### Вариант 1 — GitHub (ничего ставить не нужно)
1. Создайте репозиторий на github.com и загрузите в него содержимое этой папки.
2. Вкладка **Actions → Build APK → Run workflow** (или просто сделайте push).
3. Через 3–5 минут скачайте файл из **Artifacts → OlimpiaFood-apk**.

### Вариант 2 — Android Studio
1. File → Open → выберите эту папку, дождитесь синхронизации Gradle.
2. Build → Build Bundle(s) / APK(s) → Build APK(s).
3. APK: `app/build/outputs/apk/debug/app-debug.apk`.

Установка: скопируйте APK на телефон и разрешите установку из неизвестных источников.
